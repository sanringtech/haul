已知風險與揭露

發布給其他人用之前請先讀這份。這是個人開發的小工具，不是商業產品，作者不對此提供法律保證。

非官方端點依賴

Claude、Codex、Cursor 的用量查詢，以及 Kimi 的訂閱制用量查詢，走的都是非官方、非文件化的介面——不是這幾家公司保證會一直支援的公開合約，服務商隨時可能無預告改版或停用，屆時對應功能會失效，需要等修好。DeepSeek、Kimi 的 API key 餘額查詢走的是官方文件化的端點，不在此列。

不是官方產品

sanring Haul 跟 Anthropic、OpenAI、DeepSeek、Moonshot AI（Kimi）、Cursor 都沒有合作或任何官方關係，只是讀取你自己電腦上已經登入的本機 CLI session，或你自己貼上的 API key 去查詢用量——不會繞過任何付費牆，也不會查到不屬於你自己帳號的資料。

未簽章 / 未公證

目前處於小範圍分享階段，macOS 版沒有經過開發者簽章與公證，第一次開啟會被 Gatekeeper 擋下；Windows 版可能被 SmartScreen 擋。這不代表程式有問題，是還沒有花錢申請簽章憑證。

Windows 版未經真實測試

目前只在 macOS 上開發、只做過跨平台建置驗證，沒有人在真實 Windows 環境實際跑過——尤其是 API key 的本機儲存這塊，能不能正常運作還是未知數。

資料只存在你自己的電腦

帳號、設定、憑證全部存在本機（設定檔 + 系統的憑證管理服務），不會同步到任何雲端或伺服器，換一台電腦視同從零開始。

完整技術細節（含每個端點的確切路徑）見 RISKS.md。

完整版本說明 · v0.3.3

這個版本新增了什麼

  • Claude 用量喚醒（設定頁，預設關閉）：Claude 的 5 小時／7 天用量視窗要送出訊息才會啟動，沒用過或上一輪視窗到期後會停在「尚未開始」狀態。開啟後可以逐帳號設定每天幾點（24 小時制）送一則最小訊息喚醒視窗——這是目前唯一會真的消耗用量額度的功能，其餘都是唯讀查詢，預設關閉、要自己選帳號才生效。
  • 用量歷史折線圖：5 小時／7 天分成兩張圖表，避免不同週期的百分比混在一起誤判緊急程度；圖例可點擊個別開關某條線、顯示消耗速率。
  • 訂閱用量提醒改成單一軌道雙手柄的區間滑桿，操作更直覺。
  • 一些穩定性/UX 修正：設定頁多處開關改成點下去立即存檔；帳號改名功能擴及更多設定列。
