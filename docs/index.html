已知風險與揭露

發布給其他人用之前請先讀這份。這是個人開發的小工具，不是商業產品，作者不對此提供法律保證。

桌面唯讀監控

sanring Haul 只做「查詢」：不切換帳號、不阻擋任何 CLI 行為、不接管登入流程、不需要你的密碼。資料不出本機——CLI session 只讀，不寫回、不主動幫你 refresh。各帳號的用量彼此獨立計算，來自估算的數字一律標「估算」。

非官方端點依賴

Claude、Codex、Cursor 的用量查詢，以及 Kimi、Grok 的訂閱制用量查詢，走的都是非官方、非文件化的介面——不是這幾家公司保證會一直支援的公開合約，服務商隨時可能無預告改版或停用，屆時對應功能會失效，需要等修好。DeepSeek、Kimi 的 API key 餘額查詢走的是官方文件化的端點，不在此列。

  • Claude：呼叫 Anthropic 內部用量端點，用的是 Claude Code 自己在本機的 OAuth session。
  • Codex：呼叫 OpenAI/ChatGPT 內部端點，用的是 Codex CLI 自己在本機的登入 session。
  • Kimi 訂閱制：⚠️ 未實測——端點格式來自開源 MoonshotAI/kimi-code repo 原始碼，專案裡目前沒有人有真實 Kimi Code 帳號可以驗證。
  • Grok 訂閱制：⚠️ 未實測（本機沒有 ~/.grok）——端點格式來自開源 xai-org/grok-build。

Claude／Codex 官方「API key 制」用量查詢已查證不可行：兩家的官方 Admin 用量/成本 API 都排除個人帳號，「查詢剩餘額度」這個功能本身官方甚至都還沒實作。

多帳號怎麼運作

Claude／Codex 多帳號不依賴任何額外安裝的外部工具——做法是「擷取目前已登入的 CLI 帳號」：在對應 CLI 本機完成登入後，回到 Haul 點「＋ 新增來源」擷取一次，用帳號 email 辨識；同一 email 再擷取一次視同換票（更新憑證），不同帳號才新增一筆卡片。純讀取，不會幫你切換系統目前登入中的 CLI 帳號。

不是官方產品

sanring Haul 跟 Anthropic、OpenAI、DeepSeek、Moonshot AI（Kimi）、xAI（Grok）、Cursor 都沒有合作或任何官方關係，只是讀取你自己電腦上已經登入的本機 CLI session，或你自己貼上的 API key 去查詢用量——不會繞過任何付費牆，也不會查到不屬於你自己帳號的資料。

未簽章 / 未公證

目前處於小範圍分享階段，macOS 版沒有經過開發者簽章與公證，第一次開啟會被 Gatekeeper 擋下；Windows 版可能被 SmartScreen 擋。這不代表程式有問題，是還沒有花錢申請簽章憑證。

Windows 版

v0.4.2 已在真實 Windows 環境驗證可以啟動、載入介面，並修正 Credential Manager 寫入過大憑證失敗的問題。仍未簽章，第一次開啟可能被 SmartScreen 擋（右鍵 → 內容 → 解除封鎖）。若 Haul 裝在 Windows、AI CLI 卻登在 WSL，目前還不會自動去讀 WSL 家目錄裡的帳號。

資料只存在你自己的電腦

帳號、設定、憑證全部存在本機（設定檔 + 系統的憑證管理服務），不會同步到任何雲端或伺服器，換一台電腦視同從零開始。
